# 🍔 サンドイッチ具材 3Dモデル生成プロンプト集（ChatGPT / Codex用）

本書は、ChatGPT（Codex）アプリにそのままコピー＆ペーストして、Blender内で実行可能なPythonスクリプトを生成・出力してもらうための指示書です。

---

## 使い方（ChatGPT / Codexへの発注手順）

1. ChatGPT（Codex）アプリを開きます。
2. 下記の「共通システム指示（Prompt 0）」と、作りたい具材のプロンプトを一緒に貼り付けて送信します。
3. ChatGPTが出力した Python コード（`import bpy ...`）をコピーします。
4. Blenderを開き、**「Scripting」タブ ➔ 「新規作成（New）」** に貼り付けて **「実行（Run Script）」** を押します。
5. プロジェクトの `models/` フォルダに `.glb` ファイルとして自動出力されます！

---

## 0. ChatGPTに最初に伝える「共通前提プロンプト」

```text
あなたはBlender 4.x対応のPythonスクリプト開発のエキスパートです。
以下の仕様に従い、Webゲーム用の可愛いローポリ〜ミドルポリの3Dモデルを生成し、
.glb（glTFバイナリ）として自動エクスポートする完全なPythonスクリプトを記述してください。

【共通仕様】
1. 実行前に既存の全オブジェクト・マテリアル・メッシュをクリーンアップすること。
2. 原点（Origin）はオブジェクトの「底面中央（Z=0）」に配置すること。
3. スケールは実寸大（パンの直径が約10cm〜12cm / 0.10m〜0.12m基準）。
4. マテリアルは Principled BSDF を使用し、ゲームに適した明るく温かみのある発色にすること。
5. メッシュの法線（Normals）をスムーズシェード（Smooth Shade）にし、Auto SmoothまたはWeighted Normalを適用すること。
6. スクリプトの末尾に、現在のモデルを `models/<指定ファイル名>.glb` としてエクスポートする処理を含めること。
```

## 具材別プロンプト集

### ① トマトスライス (`models/item_tomato.glb`)
```text
【具材：スライストマト】
厚さ約 1.2cm、直径約 9cm の輪切りトマトの3Dモデルを作成してください。
・形状：少し角の取れた円盤状。
・表面ディテール：中央に仕切りがあり、タネ（黄緑がかった粒）とゼリー状の部分がわずかに表現されていること。
・マテリアル：外側の皮はジューシーな深みのある赤色（Roughness: 0.3, Subsurface: 0.1）。中央は少し透き通るような明るい赤〜オレンジ。
・出力ファイル名: models/item_tomato.glb
```

【具材：とろけるスライスチーズ】

・出力ファイル名: models/item_cheese.glb
